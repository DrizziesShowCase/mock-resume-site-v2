# docs/

Planning and reference material that isn't part of the shipped site.

- `reference/` — notes gathered *about* the real resumespice.com before writing
  any code, so the rebuild is based on an actual site structure instead of
  guesswork.
- `PRD.md` — product requirements for v1: scope (5 core pages), fictional brand,
  order-configurator flow, "Hiring Desk" design system/tokens, data model,
  milestones, and acceptance criteria. The spec to build against.
- `screenshots/` — README images, generated by `npm run screenshots`.
