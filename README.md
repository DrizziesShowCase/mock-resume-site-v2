# Mock Resume Site v2

A corporate/professional mock resume-writing business site, modeled on
resumespice.com's structure, built with React + Vite for deployment to
GitHub Pages. Practice/portfolio project — not a real business.

See `CLAUDE.md` for the project map and build status, and
`docs/reference/resumespice-site-structure.md` for the design brief.

## Dev

```
npm install
npm run dev
```
